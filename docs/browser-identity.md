# Browser identity

The static browser metadata uses the existing Reals artwork. No authentication,
routing, chat, notification, installation-prompt or offline behavior is added.

## Sources and reproduction

Android source paths are relative to the read-only `../reals-app` checkout.
The existing Web seal is byte-identical to
`app/src/main/res/drawable-nodpi/ic_notification_large.png` (512 square).
Launcher, round launcher and adaptive foreground were also visually compared.
The monochrome notification status icon is not used.

Run `node tools/generate-browser-icons.mjs` from the Web repository root with
the Android sibling available. The tool uses native Chrome canvas for decoding
and high-quality resampling, Node zlib for PNG compression, and no npm/runtime
dependencies. Set `CHROME_PATH` if Chrome is not at the default Windows path.
Chrome rasterization can vary between versions; review regenerated bytes and
rendering when upgrading the browser. The source equality check deliberately
fails if Web and Android's seal diverge.

| `/icons/icon-512.png` | Native 512 seal, avoiding enlargement of the 192 launcher | Opaque 256-color PNG |
| `/icons/icon-maskable-512.png` | Seal resized to 448 and centered at `(32,32)`; extend only its background edge pixels to fill the opaque 512 canvas | Separate opaque 256-color PNG |

The deterministic median-cut palette retains 256 colors for opaque large icons;
the tiny favicons and native launcher remain lossless. All seven image files
together are about 140 kB. Every public file is referenced by HTML or manifest.
No additional copy of the 266 kB source seal is published under public.

## Metadata and safe zone

`index.html` links absolute root URLs, uses the title `Reals` and the product
description shared with the manifest. Theme-color media queries match the
existing light Ivory `#f7f2e8` and dark Ink `#08111f` tokens. The manifest uses
the light theme as its static theme/background fallback, `name`/`short_name`
`Reals`, and `id`, `start_url`, `scope` all `/`, with standalone display.
The two general icons declare `purpose: any`; the separate maskable icon
declares only `purpose: maskable`.

The [manifest safe zone](https://www.w3.org/TR/appmanifest/#icon-masks) is the
centered circle with radius 40% of the image width (204.8 px for 512). The
generated maskable's ink/gold artwork has a measured maximum radius of 184.2 px.
`tools/check-browser-identity.mjs` verifies opacity, the safe zone, decoded
dimensions, ICO frames, MIME/status, manifest metadata, Chrome parsing and
light/dark theme references. It also renders a review sheet with actual 16/32 px
samples and circle, rounded-square and square mask previews. Review sheets in
ignored `artifacts/identity/` were visually inspected; the ring and R remain
intact and recognizable on light and dark backgrounds.
